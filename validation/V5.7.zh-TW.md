# V5.7 ModelRouter 改名驗證

驗證日期：2026-09-16。

V5.7 將公開名稱與 Skill ID 從 Model Auto Router／`model-auto-router` 改為 **ModelRouter**／`modelrouter`。為降低與現有同名專案混淆，公開首頁使用 **ModelRouter for Codex**；明確呼叫維持簡短的 `$modelrouter`。

網路盤點確認名稱並不唯一。GitHub 上已有同名 Claude Code 外掛、Claude prompt hook／feedback router、OpenAI-compatible gateway，以及多個 Codex router。最接近本專案的兩類是 Codex Skill／custom-agent delegation，以及會攔截 prompt 或位於 API data path 的 proxy／shim。本專案維持既有界線：不自動讀 prompt、不代理 API、不切換目前主對話模型，主要提供宿主內的派工判斷與可選本機輔助工具。詳見根目錄 `LANDSCAPE.md`。

| 改名風險 | 處理方式 |
|---|---|
| 新舊 Skill 同時存在而重複觸發 | 進階安裝器辨識舊目錄，先備份並安裝新目錄，成功後才移除舊目錄 |
| 新舊目錄都已有本機修改 | 視為模糊狀態，寫入前拒絕，不猜測保留哪一套 |
| AGENTS 舊 marker 遺留 | 受管舊 marker 原位換成 `modelrouter` marker；若新舊 marker 同時存在則拒絕 |
| 未標記的舊規則被誤刪 | 保留原文並輸出警告，交由使用者檢查 |
| 升級失敗造成舊 Skill 消失 | 新檔與 AGENTS 寫入前保留舊目錄；備份包含舊 Skill 與原 AGENTS |
| 舊 metrics 資料因改名遺失 | schema 不變；實機遷移只移動私人 state 目錄，不重建或虛構事件 |
| 發布包仍帶舊名稱 | ZIP 名稱、解壓根目錄、portable Skill 路徑、manifest 與安裝範例統一使用 `modelrouter` |

本機完整測試共 190 個：187 通過，3 個因目前 Windows 主機沒有 symlink 建立權限而跳過。新增測試涵蓋 legacy Skill 與 marker 遷移、正向身分辨識、同磁碟原子退役與失敗 rollback；也涵蓋跨 `AGENTS.md`／`AGENTS.override.md` 的 inactive-marker 拒絕、隔離 user/CODEX home，以及發布 log 的路徑遮蔽。新舊重複拒絕、重複安裝冪等性、junction、reparse path 與既有路由／metrics 回歸測試均通過。Skill 快速驗證為 PASS。

獨立程式審查先找出六項缺口：舊 Skill 清理失敗未回滾、任意同名目錄可能被退役、跨 guidance 檔 marker 衝突、inactive marker 受 override 遮蔽、發布驗證讀取真實 home，以及跨磁碟原子移動失敗。上述缺口已修正並加入回歸測試；最終複查沒有剩餘程式或安全性發現。這是本機代理審查，不等同第三方外部稽核。

這些結果不代表取得 ModelRouter 名稱的專屬權利，也不證明自動觸發、真實模型派工、publisher 身分或 token 節省。發布包的最終檔案數、hash、解壓後測試與 installer dry-run 結果，以 ZIP 旁的 verification JSON 為準。
